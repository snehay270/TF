🗂️ Project Structure

We'll build a simple Flask app called PyClinic — a Python equivalent of PetClinic that we'll build, test, containerize, and deploy throughout this guide.

app.py — The Flask Application
PYTHON — app.py 
from flask import Flask, jsonify, request, render_template
from prometheus_flask_exporter import PrometheusMetrics  # monitoring

app = Flask(__name__)
metrics = PrometheusMetrics(app)  # auto-expose /metrics endpoint

pets = []  # in-memory store (swap for DB later)

@app.route('/')
def home():
    return render_template('index.html', pets=pets)

@app.route('/api/pets', methods=['GET'])
def get_pets():
    return jsonify(pets)

@app.route('/api/pets', methods=['POST'])
def add_pet():
    data = request.get_json()
    pets.append(data)
    return jsonify(data), 201

@app.route('/health')
def health():
    return jsonify({'status': 'healthy'}), 200

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)

Step 3 — Jenkinsfile (Pipeline as Code)
💡

Place this Jenkinsfile in the root of your repo. Jenkins reads it automatically when you create a Pipeline job pointing at your Git repo.

GROOVY — Jenkinsfile (Python CI Pipeline) 
pipeline {
  agent any

  environment {
    VENV = "venv"
    APP_PORT = "5000"
  }

  stages {

    stage('📥 Checkout') {
      steps { checkout scm }
    }

    stage('🐍 Setup Python Env') {
      steps {
        sh '''
          python3 -m venv venv
          . venv/bin/activate
          pip install -r requirements.txt
        '''
      }
    }

    stage('🔍 Lint (flake8)') {
      steps {
        sh '''
          . venv/bin/activate
          flake8 app.py models.py --max-line-length=100 \
            --format=pylint > flake8_report.txt || true
        '''
      }
      post {
        always {
          // Archive linting report
          archiveArtifacts artifacts: 'flake8_report.txt', allowEmptyArchive: true
        }
      }
    }

    stage('🔒 Security Scan (bandit)') {
      steps {
        sh '''
          . venv/bin/activate
          bandit -r app.py models.py -f json -o bandit_report.json || true
        '''
      }
      post {
        always { archiveArtifacts artifacts: 'bandit_report.json', allowEmptyArchive: true }
      }
    }

    stage('🧪 Unit Tests (pytest)') {
      steps {
        sh '''
          . venv/bin/activate
          pytest tests/test_app.py \
            --junitxml=test-results.xml \
            --cov=app \
            --cov-report=xml:coverage.xml \
            -v
        '''
      }
      post {
        always {
          junit 'test-results.xml'
          // Publish coverage with Coverage plugin
        }
      }
    }

    stage('🐳 Docker Build') {
      steps {
        sh 'docker build -t pyclinic:${BUILD_NUMBER} .'
        sh 'docker tag pyclinic:${BUILD_NUMBER} pyclinic:latest'
      }
    }

    stage('🚀 Deploy (Docker)') {
      steps {
        sh '''
          docker stop pyclinic || true
          docker rm pyclinic   || true
          docker run -d \
            --name pyclinic \
            -p 5000:5000 \
            pyclinic:latest
        '''
      }
    }
  }

  post {
    failure {
      mail to: 'team@company.com',
           subject: "Build FAILED: ${env.JOB_NAME} #${env.BUILD_NUMBER}",
           body: "Check: ${env.BUILD_URL}"
    }
    success {
      echo '✅ Build, lint, tests, and deploy — all green!'
    }
  }
}

CHAPTER 02b — CI
GitHub Actions CI
// zero server setup — CI runs in the cloud for free
✅

GitHub Actions is the easiest way to start CI with Python — no server to install. Just create this YAML file and push to GitHub.

YAML — .github/workflows/ci.yml 
name: PyClinic CI Pipeline

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  build-test-deploy:
    runs-on: ubuntu-latest

    steps:
      # 1. Checkout code
      - name: 📥 Checkout Code
        uses: actions/checkout@v4

      # 2. Set up Python
      - name: 🐍 Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'   # cache dependencies

      # 3. Install dependencies
      - name: 📦 Install Dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      # 4. Lint with flake8
      - name: 🔍 Lint with flake8
        run: |
          flake8 app.py models.py \
            --max-line-length=100 \
            --statistics

      # 5. Security scan
      - name: 🔒 Security Scan (bandit)
        run: bandit -r app.py -ll

      # 6. Run pytest with coverage
      - name: 🧪 Run Tests with Coverage
        run: |
          pytest tests/ \
            --junitxml=test-results.xml \
            --cov=app \
            --cov-report=xml \
            --cov-fail-under=70

      # 7. Upload test report
      - name: 📊 Upload Test Results
        uses: actions/upload-artifact@v4
        if: always()
        with:
          name: test-results
          path: test-results.xml

      # 8. Build Docker image
      - name: 🐳 Build Docker Image
        run: docker build -t pyclinic:${{ github.sha }} .

      # 9. Push to Docker Hub (on main branch only)
      - name: 🚀 Push to Docker Hub
        if: github.ref == 'refs/heads/main'
        run: |
          echo "${{ secrets.DOCKER_PASSWORD }}" \
            | docker login -u "${{ secrets.DOCKER_USERNAME }}" --password-stdin
          docker tag pyclinic:${{ github.sha }} yourname/pyclinic:latest
          docker push yourname/pyclinic:latest
💡

Add DOCKER_USERNAME and DOCKER_PASSWORD in your GitHub repo → Settings → Secrets and Variables → Actions → New repository secret.

Step 3 — Write the Playbook (like a Chef cookbook)
YAML — ansible/playbook.yml 
---
- name: Setup PyClinic Web Server
  hosts: webservers
  become: yes    # sudo

  vars:
    app_dir: /opt/pyclinic
    app_user: deploy
    python_version: python3.11

  tasks:

    # Like Chef: apt cookbook
    - name: Update apt cache
      apt:
        update_cache: yes
        cache_valid_time: 3600

    - name: Install Python 3, pip, venv, git
      apt:
        name:
          - python3.11
          - python3-pip
          - python3-venv
          - git
          - nginx
        state: present

    # Create app user (secure practice)
    - name: Create deploy user
      user:
        name: "{{ app_user }}"
        shell: /bin/bash
        create_home: yes

    # Clone our Flask app
    - name: Clone PyClinic repository
      git:
        repo: https://github.com/yourorg/pyclinic.git
        dest: "{{ app_dir }}"
        version: main

    # Install Python dependencies
    - name: Install Python dependencies in venv
      pip:
        requirements: "{{ app_dir }}/requirements.txt"
        virtualenv: "{{ app_dir }}/venv"
        virtualenv_command: python3.11 -m venv

    # Create systemd service (like Tomcat service)
    - name: Deploy systemd service file
      template:
        src: pyclinic.service.j2
        dest: /etc/systemd/system/pyclinic.service
      notify: Restart pyclinic

    - name: Enable and start pyclinic service
      systemd:
        name: pyclinic
        enabled: yes
        state: started
        daemon_reload: yes

  handlers:
    - name: Restart pyclinic
      systemd:
        name: pyclinic
        state: restarted
Step 4 — Run the Playbook 
# Test connectivity first
ansible all -i ansible/inventory.ini -m ping

# Dry run (check mode — like chef dry-run)
ansible-playbook ansible/playbook.yml \
  -i ansible/inventory.ini \
  --check

# Apply for real
ansible-playbook ansible/playbook.yml \
  -i ansible/inventory.ini \
  -v              # verbose output

# Only run specific tags
ansible-playbook ansible/playbook.yml \
  -i ansible/inventory.ini \

Step 2 — Provision an EC2 Instance with Python
PYTHON — provision_ec2.py (equivalent of knife ec2 server create) 
import boto3
import time

ec2 = boto3.resource('ec2', region_name='us-east-1')

def create_instance(name: str, key_name: str) -> str:
    """Create EC2 t2.micro with Ubuntu 22.04 and return public IP."""
    instances = ec2.create_instances(
        ImageId='ami-0c02fb55956c7d316',  # Ubuntu 22.04 us-east-1
        InstanceType='t2.micro',
        MinCount=1, MaxCount=1,
        KeyName=key_name,
        TagSpecifications=[{
            'ResourceType': 'instance',
            'Tags': [{'Key': 'Name', 'Value': name}]
        }],
        SecurityGroupIds=['sg-xxxxxxxx'],  # your security group
        UserData="""#!/bin/bash
apt update && apt install -y python3 python3-pip git
pip3 install flask gunicorn
"""
    )
    instance = instances[0]
    print(f'Created instance: {instance.id}')

    # Wait until running
    instance.wait_until_running()
    instance.reload()
    print(f'Public IP: {instance.public_ip_address}')
    return instance.public_ip_address


def open_port(sg_id: str, port: int):
    """Open a port in security group — like AWS Console inbound rule."""
    sg = ec2.SecurityGroup(sg_id)
    sg.authorize_ingress(IpPermissions=[{
        'IpProtocol': 'tcp',
        'FromPort': port, 'ToPort': port,
        'IpRanges': [{'CidrIp': '0.0.0.0/0'}]
    }])
    print(f'Port {port} opened in {sg_id}')


if __name__ == '__main__':
    ip = create_instance('PyClinicServer', key_name='book')
    open_port('sg-xxxxxxxx', port=5000)
    print(f'App will be at: http://{ip}:5000')
Step 3 — Deploy WAR→Python App to EC2 with Paramiko (SSH)
PYTHON — deploy.py (equivalent of scp + ssh deploy script) 
import paramiko
import subprocess

def deploy_to_ec2(host: str, key_path: str):
    """SSH into EC2 and deploy latest app code."""
    ssh = paramiko.SSHClient()
    ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    ssh.connect(host, username='ubuntu', key_filename=key_path)

    commands = [
        'cd /opt/pyclinic && git pull origin main',
        'source venv/bin/activate && pip install -r requirements.txt',
        'sudo systemctl restart pyclinic',
        'sudo systemctl status pyclinic --no-pager',
    ]

    for cmd in commands:
        print(f'$ {cmd}')
        stdin, stdout, stderr = ssh.exec_command(cmd)
        output = stdout.read().decode()
        error  = stderr.read().decode()
        if output: print(output)
        if error:  print(f'ERR: {error}')

    ssh.close()
    print(f'✅ Deployed to {host}')

if __name__ == '__main__':
    deploy_to_ec2('ec2-52-90-x-x.compute-1.amazonaws.com', '~/.ssh/book.pem')

CHAPTER 06b — LOAD TESTING
Locust — Python Load Testing
// write load tests in Python — the JMeter alternative

📈 Locust vs JMeter

JMeter: Java GUI tool, XML test plans, hard to version-control.
Locust: Pure Python, test plans are Python code, runs in CLI or browser UI, scales to millions of users.

Step 1 — Write a Locustfile
PYTHON — locustfile.py 
from locust import HttpUser, task, between

class PyClinicUser(HttpUser):
    """Simulates a real user browsing PyClinic."""

    # Wait 1–3 seconds between tasks (realistic user behaviour)
    wait_time = between(1, 3)

    def on_start(self):
        """Called when each simulated user starts."""
        self.client.get('/')   # visit homepage first

    @task(3)   # weight=3, runs 3x more often
    def view_home(self):
        self.client.get('/')

    @task(2)
    def view_pets(self):
        self.client.get('/api/pets')

    @task(1)
    def add_pet(self):
        self.client.post('/api/pets', json={
            'name': 'LoadTestPet',
            'type': 'dog'
        })

    @task(1)
    def health_check(self):
        with self.client.get('/health', catch_response=True) as resp:
            if resp.json().get('status') != 'healthy':
                resp.failure('Health check failed!')
Step 2 — Run Locust

CHAPTER 07 — ORCHESTRATION
Full End-to-End Pipeline
// everything chained: git push → lint → test → docker → deploy → load test
🎼

This is the orchestration chapter — tie every step into one automated pipeline triggered by a single git push.

Complete GitHub Actions Pipeline (All Stages)
YAML — .github/workflows/full-pipeline.yml 
name: Full DevOps Pipeline

on:
  push: { branches: [main] }

jobs:

  # ── Stage 1: Lint + Test ──────────────────────
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.11' }
      - run: pip install -r requirements.txt
      - run: flake8 app.py --max-line-length=100
      - run: bandit -r app.py -ll
      - run: pytest tests/test_app.py --junitxml=results.xml --cov=app --cov-fail-under=70
      - uses: actions/upload-artifact@v4
        with: { name: test-results, path: results.xml }

  # ── Stage 2: Build & Push Docker Image ───────
  docker:
    needs: quality     # only runs if quality passes
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Build & Push
        run: |
          echo "${{ secrets.DOCKER_PASSWORD }}" \
            | docker login -u "${{ secrets.DOCKER_USERNAME }}" --password-stdin
          docker build -t ${{ secrets.DOCKER_USERNAME }}/pyclinic:${{ github.sha }} .
          docker push ${{ secrets.DOCKER_USERNAME }}/pyclinic:${{ github.sha }}
          docker tag  ${{ secrets.DOCKER_USERNAME }}/pyclinic:${{ github.sha }} \
                      ${{ secrets.DOCKER_USERNAME }}/pyclinic:latest
          docker push ${{ secrets.DOCKER_USERNAME }}/pyclinic:latest

  # ── Stage 3: Deploy via Ansible ───────────────
  deploy:
    needs: docker
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup SSH Key
        run: |
          mkdir -p ~/.ssh
          echo "${{ secrets.EC2_SSH_KEY }}" > ~/.ssh/book.pem
          chmod 600 ~/.ssh/book.pem
      - name: Run Ansible Deploy Playbook
        run: |
          pip install ansible
          ansible-playbook ansible/playbook.yml \
            -i ansible/inventory.ini \
            --private-key ~/.ssh/book.pem \
            -u ubuntu

  # ── Stage 4: Smoke + Load Test ────────────────
  verify:
    needs: deploy
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Smoke Test
        run: |
          pip install requests
          python -c "
          import requests, sys
          r = requests.get('http://${{ secrets.EC2_HOST }}:5000/health')
          print(r.json())
          sys.exit(0 if r.json()['status']=='healthy' else 1)
          "
      - name: Load Test (Locust)
        run: |
          pip install locust
          locust -f locustfile.py \
            --host http://${{ secrets.EC2_HOST }}:5000 \
            --users 20 --spawn-rate 5 --run-time 30s --headless

Security Scanning for Python
// bandit, safety, trivy — scan code and containers
Tool 1 — bandit (static code security analysis) 
pip install bandit
bandit -r . -ll               # scan all Python files, low-level issues
bandit -r app.py -f json -o bandit.json  # JSON output for CI
bandit -r . --skip B101       # skip assert warnings
Tool 2 — safety (check dependencies for CVEs) 
pip install safety

safety check --json > safety_report.json # CI output
Tool 3 — trivy (Docker image vulnerability scan) 
# Install trivy
curl -sfL https://raw.githubusercontent.com/aquasecurity/trivy/main/contrib/install.sh | sh -s -- -b /usr/local/bin

# Scan your Docker image
trivy image pyclinic:latest

# Fail CI if HIGH/CRITICAL vulns found
trivy image --exit-code 1 --severity HIGH,CRITICAL pyclinic:latest
Add All 3 Scans to GitHub Actions

  security:
    runs-on: ubuntu-latest

      - uses: actions/checkout@v4
      - run: pip install bandit safety
      - name: bandit scan

      - name: dependency CVE check
        run: safety check -r requirements.txt
      - name: container scan
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: pyclinic:latest
          severity: HIGH,CRITICAL
          exit-code: '1'
